# Physical AI 応用1 最終課題：AIで仕分け先を決める移動ロボット

## 内容
荷物の色と形をカメラ画像に見立てたデータから分類し、差動二輪ロボットで仕分け先まで運ぶ簡単なシミュレーションを作りました。

- 赤い四角：MEDICINE
- 青い丸：WATER
- 緑の三角：FOOD

画像から特徴を6個取り出して、小さなMLP（`scikit-learn`）で分類します。その結果でロボットの目的地を選びます。ロボットは左右の車輪の回転速度を計算して、向きを変えながら目的地まで進みます。動画では車体、2つの車輪、カメラ、簡単な荷台（フォーク）を描いています。

**注意**：これはPythonの簡易2Dシミュレーションです。Gazeboや実機で動かしたものではありません。荷物の積み降ろしはプログラム上の処理であり、物理的な把持の再現はしていません。画像も実際のカメラ撮影ではなく合成画像です。

## 動かし方
Python 3.10以上を想定しています。作業フォルダで以下を順番に実行します。

```bash
pip install -r requirements.txt
python run_project.py
python make_video.py
```

`results/sorting_robot.mp4` が動画です。`results/metrics.json` に分類精度と搬送件数、`results/robot_log.csv` に車輪の速度と位置の記録を保存します。

## ファイル

- `run_project.py`：画像の学習とロボットの走行
- `src/ai_vision.py`：合成画像・特徴抽出・MLP分類
- `src/robot_sim.py`：左右車輪の速度による位置更新と目的地への移動
- `make_video.py`：走行ログからMP4を作る
- `compare_speed.py`：走行速度を変更して動作時間を比較
- `results/`：動画と動作ログ

## 確認したこと

- 画像分類のテストデータ165枚では165枚正しく分類できました。ただし単純な合成画像だけを使った結果です。
- 荷物4個の仕分けを確認できました。最大速度0.60 m/sで約91.5秒でした。
- 最高速度を0.35 m/sに落とすと約130.5秒かかったので、提出用の動画では0.60 m/sを使っています。
- 最初は移動体を丸だけで描いていましたが、ロボットに見えにくいため、車体・車輪・荷台と左右の車輪速度の表示を加えました（走行制御は同じ）。
